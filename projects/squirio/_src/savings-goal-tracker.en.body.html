Define a target amount and deadline, subtract money already saved, divide the gap by the remaining contribution periods, and record every deposit or withdrawal. Review progress when income or the deadline changes.

Calculate the required contribution

Suppose an emergency-fund target is Rp12,000,000, Rp3,000,000 is already set aside, and nine months remain. The remaining Rp9,000,000 requires Rp1,000,000 per month. Include fees or expected price changes when the goal is a purchase.

Keep emergency savings, planned purchases, and long-term goals separate so you can see the amount and deadline for each one.

Calculate progress from transactions

  1. Create a named goal with an amount and deadline.
  2. Choose the account that holds the funds.
  3. Record each contribution as a transfer to that account.
  4. Record withdrawals so the progress remains accurate.
  5. Compare goal progress with the account balance.

Squirio derives goal progress from linked transactions, so correcting an older entry changes the result. That keeps the target consistent with the financial record rather than a manually edited progress bar.

Update the plan when a contribution changes

If a contribution is missed, choose among a later deadline, a smaller target, or larger future contributions. Do not mark money as saved before it has moved. Include contributions in the monthly budget alongside other expenses.
