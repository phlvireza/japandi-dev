Squirio stores its working data in one SQLite database inside the app's private storage. There is no Squirio account or automatic cloud copy.

Reduce the number of places financial data travels

Core entry, budgeting, reporting, and insight features run on the device. Airplane mode is therefore a useful product test rather than a degraded fallback.

Make leaving possible

Local-first should not mean locked in. Squirio can export transactions to CSV and create a complete zip backup through Android's share sheet. The user chooses the destination.

Exports are explicit actions. The app does not create a remote copy in the background.

Ownership includes recovery responsibility

If the phone holds the only copy and is lost or damaged, the records are lost too. The interface must explain that plainly and make regular backups easy to create and restore.

This tradeoff avoids pretending that local storage is risk-free. It replaces an automatic cloud dependency with visible user control.
