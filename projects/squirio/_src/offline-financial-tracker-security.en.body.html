An offline tracker avoids some risks associated with remote accounts and provider databases. It still depends on the phone's security, the app's design, and how backups and exports are stored.

List the events you need to protect against

Consider four events: someone gains access to an unlocked phone; the phone is infected with malware; a backup is exposed; or the device is lost without a recoverable copy. Offline storage reduces some remote-service risks but does not protect against every case.

Squirio is a local-first Android app that does not require an account for core use. Records remain on the device unless the user creates an export or backup. The no-account guide explains its storage and synchronization limits.

Use safer operating practices

  1. Protect the device with a strong screen lock and current system updates.
  2. Install apps from trusted sources and review unusual permissions.
  3. Hide sensitive notification content on the lock screen.
  4. Store backup copies separately with access controls.
  5. Delete temporary exports when they are no longer required.
  6. Test recovery before replacing or resetting the phone.

With local storage, the user is responsible for recovery. Losing the only copy means losing access, even if nobody else sees the data.
